# Strengths / Weaknesses Review — Immigration with NIPTEI portal
**Date:** November 28, 2026 — founder's request ("any suggestion and implement, strength weakness implemented what is needed, think of the professional and the client").
**Scope:** `portal/` (Next.js 14, TypeScript) + `supabase/migrations/` 0001–0031 at time of review. Audited before building; nothing here duplicates another builder's work — every "fixed" item below is a gap that had no code yet. No `npm run build` was run (coordinator runs one clean build at the end); `npx tsc --noEmit` exits 0.

**Standing rules (not re-decided here):** document preparation only, NOT a law firm, NOT USCIS-affiliated; only a licensed attorney or DOJ-accredited representative gives legal advice (8 CFR 292.1); no AI decides relief/eligibility/evidence strength/safe-to-leave; no approval is ever promised. Locked prices and Stripe Price IDs in `src/lib/stripePrices.ts` were not changed. Pay-before-access is via Stripe checkout/webhook, DB-confirmed, never a front-end flag. DOB / A-Number / SSN / passport numbers are masked in UI, never logged, never in email subjects. Email is AWS SES via `src/lib/email.ts` (501 `email_not_configured` when unconfigured, never claims sent).

## 1. Professional side

### Strengths (with file evidence)
1. **Payments — platform checkout is real and locked.** Stripe checkout + webhook (`src/app/api/checkout/route.ts`, `src/app/api/stripe/webhook/route.ts`), 132 locked Price IDs (`src/lib/stripePrices.ts`), smoke-tested (`scripts/smoke-stripe.ts`). Pay-in-3 / monthly splits are exact-cent correct (`src/lib/stripe.ts` `splitInvoices`).
2. **BYO model is honest and safe.** `src/lib/byo.ts` + `provider_settings` (migration 0014): each professional connects their own Resend / SES / Twilio / WhatsApp / video / calendar / e-sign / storage / Google Translate / own Stripe; keys as encrypted reference + last-4 only, never plaintext, never logged; sends return `not_configured` until connected + tested; test-send only to the professional's own email/phone. UI: `src/components/comms/ByoSettings.tsx`.
3. **Booking requests are collected, never faked as booked.** `src/lib/booking.ts`, `/api/bookings` (GET/POST/PATCH), `preparer_appointments` (0012 + decision columns 0017) + `consultation_requests` (0017, locked $0 15-min / $99 30-min, price enforced by CHECK). Calendar is labelled NOT connected everywhere.
4. **Pipeline is shared, private and payment-derived.** `src/lib/pipeline.ts` + `src/components/pipeline/ClientPipeline.tsx`: one shared component for preparer/attorney/DOJ, DOB masked (`maskDob`), payment status derived only from `invoices.status` / `order_invoices.status`, draft emails shown to the professional first, SES 501 when unconfigured.
5. **Reporting is real-rows-only.** `src/lib/reporting.ts`: pure aggregation over `invoices` / `order_invoices` / `payment_plans` / lifecycle / leads / notification logs; service vs USCIS government fees always separate; empty input returns zeros + `isEmpty` (the old $17,812 demo Money Ladder was removed, not copied).
6. **Vault expiry is careful.** `src/lib/vaultExpiry.ts` + `documents.expires_on` (0029): passport / medical / police-clearance dates come from the document itself, no fixed validity period is invented, translations never expire, no date on file is never guessed.
7. **Messaging is one thread with honest delivery.** `src/components/comms/UnifiedThread.tsx`, `/api/messages/send`: portal chat stored in `messages` + `message_sends` (0014); SMS/WhatsApp return 501 `not_configured` until BYO Twilio is connected; uncertain translations flagged, never auto-sent as certain.
8. **Guardrails are in the dashboard, not an appendix.** `src/components/preparer/PreparerDashboard.tsx` + `ComplianceGuardrails`, `AttorneyHandoff`, `StudentSupervisionGuardrail`, UPL badge — the preparer sees the clerical-only boundary on the default tab.

## 2. Client side

### Strengths (with file evidence)
1. **The client is never promised an outcome.** Client dashboard (`src/app/client-dashboard/page.tsx`) and preparer pages repeat the clerical-only / not-a-law-firm / no-approval-guarantee wording; the journey, intake and DIY flows never state eligibility or a safe-to-leave answer.
2. **Pay-before-access is real, not a flag.** Locked bundle prices ($999 / $1,799 / $2,799), checkout + webhook confirmation; DIY unlocks check payment server-side (`src/app/api/diy/unlock-status/route.ts`).
3. **The client's own numbers are masked.** DOB masked (`••/••/1990`, `pipeline.ts` `maskDob`), receipt numbers masked (`src/lib/caseTracking.ts`), A-Number masked (`src/lib/agency.ts`); no SSN column exists anywhere.
4. **Vault + renewal radar are client-visible.** `VaultExpirySection`, `RenewalRadarSection` on the dashboard: the client sees what expires and when, with translations honestly never expiring.
5. **One thread, one language.** Unified thread with original + translated text, uncertain translations flagged for human confirmation; interview prep, fee-waiver checker and total-cost estimator are on the dashboard, not hidden.
6. **Consultation pricing is locked and visible.** Free 15-min / $99 30-min (`src/lib/booking.ts`), enforced by a database CHECK — a client cannot be charged a different consultation price by the UI.

### Client-side weaknesses NOT fixed in code (need a human / later build)
- Client sign-in is not wired live, so no client-facing "my requests / my invoices / my signatures / my unread" page can be built honestly yet — building one against example ids would fake a login. The shared helpers (`countUnreadByCase`, `mergeCalendarEvents`, `listProfessionalInvoices`, `buildSignatureRequest`) are written to be reused by those pages when sign-in lands.
- No live USCIS status, no live NVC/CEAC status: status is entered manually from what USCIS Case Status Online says (`src/lib/caseStatusSync.ts`, `CaseStatusSync.tsx`) — a live USCIS key is not connected and is not claimed.
