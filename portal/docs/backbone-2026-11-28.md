# Immigration backbone — USCIS · NVC · Embassy (NINTH ADDITION, Nov 28, 2026)

Founder's brief: "make sure the backbone of immigration that everyone need even immigration, USCIS, NVC and the embassy." The platform must cover the whole immigration journey in one place. This doc is the backbone check: what is covered, what is still a manual step, and what this addition filled.

## What was already there (read before building)

The parallel case-number tracking builder (EIGHTH ADDITION, Nov 28, 2026, `src/lib/caseTracking.ts`) had already built most of the USCIS and NVC backbone:

- USCIS receipt validation + masking, public status words + explainer, status-change log, completeness view.
- RFE / NOID decoder (notice words → plain English + clerical steps; NOID always attorney-review).
- Consular online-submission checklist, NVC public contact, "no embassy email stored anywhere" rule.
- The NVC engine itself (`src/lib/nvc.ts`): 13-character case validation, post lookup (BGT is Bogotá, BOG is not), CEAC 6 steps, DOS fees $120 AOS + $325 IV, K-1 separate track, $235 immigrant fee + 30–90 day post-arrival window.
- Lifecycle stages 1–6 + 5A/5B (`src/lib/lifecycle.ts`), route steps (`src/lib/nextStepEngine.ts`), interview prep banks (`src/lib/interviewPrep.ts`).
- Filing facts scattered in `src/lib/diySubmission.ts` + `src/lib/intakeCalculator.ts` (G-1450 / G-1650, one payment per form).

This addition REUSES all of that. Nothing above was rebuilt.

### Deliberate divergence to reconcile

The eighth addition (`src/lib/caseTracking.ts`, `EMBASSY_CONTACT_NOTE`) decided "no embassy email address is stored anywhere in this portal." This task's brief asks for the email "only from official guidance already in the codebase or a travel.state.gov source you cite" — so this addition stores the 3 verified above, each with its official source + date, and stores none for the other 9. The coordinator should confirm which rule governs going forward; nothing here is unverified either way.

### Two flags found while verifying (not silently adopted)

- **Bogotá K-visa fee:** the Bogotá official page states a $275 MRV fee for K (fiancé(e)) visas. The platform's K-1 $265 figure stays **TO BE CONFIRMED** — the $275 was recorded as a flag on the BGT entry, not adopted as the fee.
- **Caracas / Venezuela:** Bogotá also schedules immigrant visa interviews for residents of Venezuela — the CRS entry says to check the interview letter for which post the interview is at.

### Bug found by the check and fixed

The codebase's own example NVC case numbers **failed its own validator**: `PHP2026514009` (in `lib/nvc.ts` `EXAMPLE_NVC_CASE`, the default in `CeacTracker`) parses as Julian day **514**, and `CRS2026600002` (in `lib/agency.ts`) as Julian day **600** — both outside the 001–366 range `parseNvcCaseNumber` enforces. The tracker's default view therefore showed an invalid case number. Fixed to valid examples with the same shape: `PHP2026144009` (PHP + 2026 + 144 + 009) and `CRS2026144002`, including the header comment, the validator's error-message example, the `K1NvcTracker` placeholder, and the `CaseCommandPanel` label. The smoke test now asserts the canonical example is valid and the old numbers are rejected. (Two stale references remain in `scripts/test-platform.js` and `DEPLOY.md` — label-only, not user-facing validation — left untouched and noted here.)
